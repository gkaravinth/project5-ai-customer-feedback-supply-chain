# Git Workflow Commands

This file documents the Git commands used to initialize, commit, and push this project to GitHub.

## Initial Git Setup

```bash
git init
git branch -M main
git remote add origin https://github.com/gkaravinth/project5-ai-customer-feedback-supply-chain.git


Check Status
git status

Add Files
git add .

Commit Changes
git commit -m "Initialize Project 5 structure and documentation"

Push to GitHub
git push -u origin main

git status
git add .
git commit -m "Your clear commit message here"
git push



Important Notes
Do not commit access keys, tokens, passwords, or secrets.
Use clear commit messages.
Run git status before committing.
Push only tested and safe files.
